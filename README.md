# Anline Nails — сайт студии

React + Vite. В проект добавлены локальные фотографии студии: 15 работ и 3 фотографии интерьера в `public/images/`.

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка для публикации (Vercel)

```bash
npm run build
```

Для Vercel:
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`

Все фотографии загружаются локально из `public/images`, внешние фотохостинги не используются.

## Важно

Прайс и длительность процедур перенесены из опубликованной карточки Anline. nails на Яндекс Картах. В самой карточке прайс отмечен как давно не обновлявшийся, поэтому актуальные суммы нужно подтвердить у студии.
